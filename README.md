# 株主優待メモ

保有51銘柄の株主優待を、iPhoneから管理する自分用のWebアプリ(PWA)。優待の有無・内容・条件、実際に届いた優待の使用期限、応募しないともらえない株主特典の締切を、一か所で見られるようにする。構成は「読書メモ」(tadamasa/reading-memo)と同じ。

## 画面

| タブ | できること |
|---|---|
| 優待 | 保有株式と優待マスタを証券コードで結合した一覧(銘柄名・コード・株数・優待の有無・種類・内容・条件・権利確定月)。検索、有無での絞り込み、並べ替え。上の「暦帯」は12か月の権利確定月で、押すとその月で絞り込む。銘柄を開くと優待の編集フォームと、その銘柄の受取・特典 |
| 受取・使用 | 届いた優待を使用期限の近い順に。期限切れは紅、30日以内は金で強調。使い終えたものは別の表示に。追加・編集・削除 |
| 特典 | 応募型の株主特典を札(カード)で。締切までの残り日数を大きく出し、応募ステータスをその場で変えられる。追加・編集・削除 |
| 設定 | 株主優待ハブのURLと合言葉、今すぐ同期、最終同期日時、保有株数の更新日時、バックアップ、使い方の物語 |

初回起動時は `seed.json`(保有51件・優待51件・特典1件。2026-11-13 時点の株主優待ハブとポートフォリオと同じ中身)から読み込むので、ハブにつなぐ前から一覧が出る。

## 特徴

- **サーバーなし・運用費0円**: 画面は GitHub Pages、データは端末(IndexedDB)と自分のスプレッドシート。外部CDN・外部フォントは使わない。
- **ハブ同期**: スプレッドシート「株主優待ハブ」+ Apps Script(`hub/Code.gs`)。端末用とさくら用の二つの合言葉、rev による差分取得、id での upsert、mtime の新しい方が勝つ。表を直接書き換えてもアプリに届く。手順は [hub/README.md](hub/README.md)。
- **保有株数は正本を読むだけ**: ポートフォリオ「保有株式」をハブが読み取り専用で返し、アプリが証券コードで結合する。ハブには複製しない。
- **圏外でも開ける**: Service Worker でアプリ本体をキャッシュ。
- **主題「熨斗紙と水引」**: 生成りの紙に紅と金の細い紐。紅=優待あり・期限切れ、金=要確認・期限が近い、鼠=なし・使い終えた。見出しは明朝(端末の Hiragino Mincho)。ライト/ダーク対応。

## 使い方(iPhone)

1. https://tadamasa.github.io/yutai-memo/ を Safari で開き、共有ボタンから「ホーム画面に追加」する(追加しないと Safari が保存データを消すことがある)。
2. ホーム画面のアイコンから開く。最初から51銘柄が出る。
3. 設定 → 株主優待ハブ(同期) に、ハブのURLと合言葉を入れて「接続して同期する」。

## 開発

ビルド不要。ES Modules のまま配信する。仕様は [docs/spec-v01.md](docs/spec-v01.md)。

```sh
npm run serve   # http://localhost:8766
npm test        # Node 20以降。計算と、hub/Code.gs を模擬のApps Scriptで動かすテスト
```

**出すたびに `sw.js` の `VERSION` を上げ、ファイルを足したら `SHELL` にも足す。** 上げないと、ホーム画面のアプリに新しい版が届かない。

| ファイル | 役割 |
|---|---|
| `index.html` | 外枠(ナビ・タブバー) |
| `js/app.js` | 画面とルーティング |
| `js/yutai.js` | 画面に触れない計算(日数、権利確定月の読み取り、結合、絞り込み、並べ方)。テスト対象 |
| `js/words.js` | 画面の言葉と選択肢(ここだけ直せば言い回しが変わる) |
| `js/db.js` | IndexedDB の薄いラッパー(DB名 `yutai-memo`) |
| `js/sync.js` | 株主優待ハブとの同期 |
| `js/backup.js` | JSONの書き出し・読み込み |
| `css/hig-*.css` | Apple HIG に沿ったトークンと部品(読書メモと共通) |
| `css/app.css` | 主題の色・間・動き(先頭の変数で調整) |
| `seed.json` | 初回起動時の初期データ |
| `hub/Code.gs` | ハブ(Apps Script) |
| `tests/` | `node --test`。`gas-mock.mjs` は SpreadsheetApp などの模擬 |
